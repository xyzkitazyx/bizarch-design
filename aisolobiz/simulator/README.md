# AIで一人個人事業の教科書 収支シミュレーター v1.0

副業／専業の2モードで、個人事業主の手取りと税負担を即座に試算するWebシミュレーターです。

## 概要

- **対象読者**：副業を始めたい会社員、専業フリーランス、法人成り検討中の個人事業主
- **データ前提**：2026年4月時点・東京23区基準
- **計算範囲**：所得税・住民税・国保・国民年金・iDeCo/共済/基金/専従者・青色控除

## ファイル構成

| ファイル | 用途 |
|---|---|
| `index.html` | UI（入力フォーム＋結果表示） |
| `style.css` | スタイル（bizarch-design準拠） |
| `script.js` | 計算ロジック＋UI更新 |
| `data.json` | 業種プリセット・税率・自治体マスタ |
| `test_node.js` | 5ケースの自動検証（`node test_node.js`） |

## 起動方法

ローカルでブラウザの`fetch()`制限を回避するため、簡易HTTPサーバが必要です。

```
cd 05_simulator
python -m http.server 8000
# → http://localhost:8000 を開く
```

または VSCode の Live Server 拡張、`npx serve` などでも可。

## 主な機能

### 1. モード切替（副業／専業）
- 副業モード：給与＋事業所得を合算累進で計算
- 専業モード：事業所得＋国保＋国民年金で計算

### 2. 共通入力
- 業種プリセット（受託開発・AXコンサル・業務設計コンサル・BAコンサル・経営コンサル・広告運用・ウェブ制作・ウェブデザイン・カスタム）
- 年商・経費（うちAI関連経費）
- 自治体（東京23区・大阪市・名古屋市・札幌市・福岡市・その他）
- 申告区分（青色65万／青色55万／青色10万／白色）

### 3. 副業モード追加入力
- 本業給与年収
- 配偶者年収・扶養家族数
- 配偶者の社保被扶養者の有無
- 住民税の徴収方法（普通／特別）

### 4. 専業モード追加入力
- iDeCo月額（最大68,000円）
- 小規模共済月額（最大70,000円）
- 国民年金基金月額（iDeCo合算で68,000円）
- 専従者給与の有無＋月額
- 40歳以上（介護分の国保加算）

### 5. 6つの壁判定
- 副業：103/106/130/150/200万
- 専業：48万・1,000万（インボイス）
- 法人成り：課税所得600万 or 年商800万
- 黄／赤／緑／青で警告レベル別表示

### 6. 弥生CTAボタン（動的表示）
- 副業少額帯（事業所得<50万）：弥生白色申告オンライン
- 青色推奨（事業所得≥50万）：弥生青色申告オンライン
- 開業前/開業届未提出：弥生「開業届」

### 7. 法人成り推奨アラート
- 課税所得600万超 or 年商800万超で表示
- 法人版シミュレーターへの誘導ボタン

## 計算ロジック

### 副業モード
```
給与所得 = 給与年収 - 給与所得控除（最低55万・上限195万）
事業所得 = 売上 - 経費 - 青色控除（65/55/10/0）
合計所得 = 給与所得 + 事業所得
給与社保 = 給与年収 × 14.4%（簡易概算）
所得税課税所得 = 合計所得 - 給与社保 - 基礎48万 - 配偶者控除等
所得税 = 累進5/10/20/23/33/40/45% - 控除額
復興特別所得税 = 所得税 × 2.1%
住民税 = (合計所得 - 給与社保 - 基礎43万 - 配偶者控除33万) × 10% + 均等割5,000円
手取り = 給与年収 - 給与社保 + (売上-経費) - 税合計
```

### 専業モード
```
事業所得（青色前）= 年商 - 経費 - 専従者給与
事業所得（青色後）= 上記 - 青色控除
国保 = (事業所得 - 43万) × 13.7% + 66,000円（東京23区。上限109万）
　　　※ 40歳以上は介護分（料率2.34%＋均等割16,200円）追加
国民年金 = 17,510円 × 12 = 210,120円
共済等控除 = iDeCo + 共済 + 国年基金（iDeCoと国年基金は合算で年816,000円上限）
所得税課税所得 = 事業所得 - 国保 - 国民年金 - 共済 - 基礎48万
所得税 = 累進5-45% - 控除額
住民税 = (上記 - 住民税基礎43万) × 10% + 均等割5,000円
手取り = 年商 - 経費 - 専従者 - 国保 - 国民年金 - 共済 - 税合計
```

## 自動テスト

`test_node.js` で5ケース・18アサーションを検証。

```
node test_node.js
```

期待値はnote第1章「手取り早見表」（給与400万モデル副業6パターン・専業6パターン）と整合させて設計。
許容誤差は10万円〜25万円で、教科書値の±5%以内に収まることを確認。

| # | 内容 | 期待値（参考） |
|---|---|---|
| 1 | 副業：給与400万＋事業所得+100万・青色65万 | 手取り約432万（給与手取り342＋事業89.5） |
| 2 | 専業：年商600万・経費150万・iDeCo月23,000円 | 手取り約290〜330万 |
| 3 | 専業：年商1500万・経費300万・iDeCo＋共済フル | 手取り約680〜760万 |

## 簡略化している部分（既知の制限）

- **副業者の給与社保**：給与年収×14.4%の固定概算（厳密には標準報酬月額の等級で決まる）
- **配偶者特別控除**：150万→201万を直線で減額（実際は5段階）
- **国保**：基礎控除43万を所得から差し引いた後の所得割（自治体による細部の差は無視）
- **住民税の均等割**：5,000円固定（自治体による1,000〜2,000円の差は無視）
- **所得税の合算累進**：副業モードは「合計所得を累進」で計算（早見表は「追加分の限界税率」で簡易計算なので若干差が出る）
- **インボイス・消費税**：警告のみ表示、税額は計算に含めない

これらの簡略化により、教科書早見表との差は5〜10%程度に収まっています。**実際の確定申告は弥生青色申告等で正確に計算してください。**
